# ServAlve Dashboard

Premium enterprise refund integrity console — **React**, **Tailwind CSS v4**, **Framer Motion**.

## Setup

```bash
cd /Users/dishusoni/servalve-dashboard
npm install
npm run dev
```

> Requires `framer-motion` (listed in `package.json`). Run `npm install` if you see a missing-module error.

## Features

- **48px Playfair Display** logo + tagline
- **Network Status** ribbon (integrity, latency, signature index)
- **Scroll-driven spring cards** (stiffness 100, damping 20)
- **Floating Hex Viewport** beside evidence ingest
- **Emerald inner glow** on pass verdict
- **Demo Override** modal (click ServAlve): ChatGPT, Gemini, Hardware Pass, Timeline Anomaly
- Native **FileReader** byte forensics in `src/forensics/engine.js`
